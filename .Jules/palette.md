## 2024-05-24 - Accessible 3D Status Messages in WebXR
**Learning:** 3D text meshes in WebXR are inherently inaccessible to screen readers.
**Action:** Synchronize 3D text changes to a 2D HTML element with ARIA attributes (e.g., `aria-live="polite"`) placed inside the WebXR `dom-overlay` with a visually hidden `.sr-only` class to make AR status updates accessible without breaking the visual AR experience.
