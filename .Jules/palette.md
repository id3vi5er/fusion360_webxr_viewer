## 2026-04-24 - WebXR DOM Overlay and 3D Text Accessibility
**Learning:** 3D text meshes in WebXR are inherently inaccessible to screen readers. In WebXR DOM overlays, the root element must not have `style="display: none;"` as it prevents rendering during the XR session and completely removes contained ARIA regions (like `aria-live`) from the accessibility tree.
**Action:** To provide accessible status updates, synchronize 3D text changes to a 2D HTML element with ARIA attributes (e.g., `aria-live="polite"`) placed inside the WebXR `dom-overlay`, and use the standard `.sr-only` CSS class pattern to visually hide text while keeping it accessible to screen readers.
