## 2026-06-19 - Screen Reader Accessibility in WebXR
**Learning:** In Three.js WebXR applications, 3D text rendered onto canvas meshes (like the debug panel) is completely invisible to screen readers. To make XR status updates accessible, we must synchronize the 3D text changes to a visually hidden (`.sr-only`) HTML element with `aria-live="polite"` attributes placed inside an explicit `dom-overlay` configured via the `ARButton`. Furthermore, the root of the overlay must have `pointer-events: none` to avoid blocking interactions with the 3D canvas, and must NOT have `display: none` as this hides it from the accessibility tree.
**Action:** When adding 3D text or UI to an XR scene, always add a parallel DOM overlay with ARIA live regions to ensure screen reader users receive the same state information as sighted users.
